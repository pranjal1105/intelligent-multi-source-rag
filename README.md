# Enterprise AI Retrieval System

An advanced multi-source AI retrieval platform designed to simulate real-world enterprise AI systems.

This project goes beyond a basic RAG chatbot by intelligently routing user queries across multiple data sources including:

- Vector Databases
- SQL Databases
- Web Sources

The system will support:
- advanced document ingestion
- OCR and table extraction
- intelligent query routing
- hybrid retrieval
- response synthesis
- source attribution
- conversational context
- Streamlit-based UI

---

# Project Goals

The objective of this project is to build a production-style AI engineering system suitable for:

- AI Engineer interviews
